# edh-deck-builder

Provides a deck-building interface that provides card role data metrics to help build the best EDH deck possible.

## Getting Started in VS Code

### Prerequisites

1. Install **.NET Framework 4.7.2 Developer Pack**.
2. Download [nuget.exe](https://nuget.org) and add it to your system **PATH**.
3. Ensure **MSBuild** (from your Visual Studio/Build Tools installation) is added to your system **PATH**.
4. Install the **C# Dev Kit** extension in VS Code.

### Setup & Run

1. **Restore Packages:** Open the VS Code integrated terminal and run:
   ```bash
   nuget restore
   ```
2. **Build the Project:** Press `Ctrl+Shift+B` (or `Cmd+Shift+B`) to run the automated build task.
3. **Run & Debug:** Press `F5` to launch the application with the 64-bit Windows debugger active.
